# EventHub - Event Organizer Discovery Platform

A modern, responsive frontend web application inspired by Justdial.com for discovering and connecting with event organizers.

##  Features

### Home Page
- **Navigation Bar**: Logo, search bar, and city/location selectorr
- **Hero Section**: Large search interface with event type and location filter
- **Category Grid**: Visual categories for Wedding Planners, Birthday Organizers, Catering, Decoration, Photography, and Music & DJ
- **Featured Organizers**: Showcase of top-rated event organizer

### Listing Page
- **Card-based Layout**: Clean, modern organizer cards with essential informatio
- **Advanced Filters**: Filter by event type, budget range, and rating
- **Sorting Options**: Sort by relevance, rating, or pric
- **Pagination**: Easy navigation through multiple pages of result

### Organizer Profile Page
- **Detailed Information*: Comprehensive organizer details and service
- **Image Gallery**: Visual portfolio of past eventt
- **Contact Information**: Easy ways to connect with organizerss
- **Reviews & Ratings**: Social proof and quality indicatorss
- **Quick Stats**: Key metrics like events completed and clients served

## 🛠️ Technology Stack

- **HTML5**: Semantic markup for accessibility and SEO
- **CSS3**: Modern styling with responsive design
- **JavaScript**: Interactive functionality and dynamic content
- **Font Awesome**: Icon library for better visual appeal

##  Responsive Design

The application is fully responsive and works seamlessly across:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (320px - 767px)

##  Getting Started

1. Clone or download the project file
2. Navigate to the project directory
3. Open `index.html` in your web browser

No build process or server setup required - it's a pure frontend application
